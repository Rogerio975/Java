# Calculadora Simples JavaFX

Projeto JavaFX simples para operações básicas de calculadora: adição, subtração, multiplicação, divisão, ponto decimal e limpar.

## Estrutura
- `pom.xml` - configurações Maven e dependências JavaFX
- `src/main/java/com/example` - código Java
- `src/main/resources/com/example/primary.fxml` - layout da interface

## Como executar
No Windows:

```powershell
cd "c:\Users\e144231\analiseSistemas\Java\Calculadoras\CalculadoraJavaFX\calculadora"
.\mvnw clean javafx:run
```

## Requisitos
- JDK 11+
- Internet ao executar pela primeira vez para baixar as dependências do Maven Wrapper
